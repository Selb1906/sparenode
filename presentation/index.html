왜 만들었나

연구용 컴퓨팅은 늘 모자라고,
주머니 속 8코어는 놀고 있다

  • 노트북 AI가 SSH로 데스크톱에 작업을 나눠 주며 쓰는 중
  • 그래도 반복 계산이 많은 실험(워터마크 검출 점수 계산 등)은 오래 걸림
  • 데스크톱 GTX 1070은 FP16이 매우 느린 세대 → 최신 폰이 더 빠를 때도 있음
  • 폰·공기계는 사실상 미니 PC인데 연산에는 쓰지 않음

기존 방법의 불편함

  • 폰에서 연산하려면 Termux 등 별도 앱 설치·설정
  • 검증 안 된 분산 연산 앱은 회원가입·권한 요구
  • 작업이 바뀔 때마다 앱을 새로 만들어야 하는 구조는 곤란

구조

노트북이 나누고, 켜져 있는 기기가 알아서 계산해 돌려준다

노트북 AI · 스크립트작업 코드와 데이터 묶음 제출
run_job(code, inputs)
→
코디네이터 (노트북)빈 코어가 있는 기기에 묶음 자동 배정
끊기면 다른 기기로 재배정 · 토큰 인증
파이썬 표준 라이브러리만 사용
⇄
폰 SpareNode 앱8코어 워커가 자동 실행
노트북 브라우저20코어
데스크톱 · 공기계같은 앱으로 참여 (예정)

버튼 없이
앱을 열면 자동 접속, 작업이 오면 바로 처리

앱은 그대로
작업 코드를 실행 중에 받아서, 작업이 바뀌어도 앱 재배포 불필요

결과만 반환
RAM을 빌리는 게 아니라 일을 나눠 맡김

왜 PWA인가

설치 파일·회원가입 없이, 브라우저 격리 안에서 안전하게

PWA (이번 방식)네이티브 앱 / Termux
설치주소 열고 '앱 설치'스토어·APK·패키지 설정
안드로이드·아이폰하나로 둘 다각각 따로
보안브라우저 샌드박스
폰 파일·다른 앱 접근 불가		앱 권한에 따라 다름
오프라인서비스 워커로 실행가능
한계화면이 켜져 있어야 계산 (백그라운드 실행 불가) → 측정·연결 중 화면 꺼짐 방지

PWA를 이루는 파일

  • manifest.json 이름·아이콘·전체 화면
  • service-worker.js 앱 파일 저장, 오프라인 실행
  • icons/ 192·512·180px (SVG 하나에서 생성)

글꼴 원칙

구글 글꼴 등 외부 글꼴 연결 없음 → 기기 기본 글꼴만 사용해 첫 화면 로딩을 빠르게

에너지 관점

새 장비를 사지 않고, 이미 있는 기기의 유휴 연산을 쓴다

  • 폰은 1분 전력 소모 측정 중 배터리 −1% (B1·B2 각각)
  • S26 Ultra 배터리(5,000mAh ≈ 19Wh 가정) 기준 약 12W로 추정
    배터리 표시가 1% 단위라 대략적인 값
  • 같은 시간 동안 노트북보다 더 많은 token을 처리 → 와트당 처리량은 폰이 유리할 가능성이 큼
  • GTX 1070은 보드 전력만 150W급

정직하게 남은 것

  • 노트북·데스크톱 전력은 아직 직접 측정하지 않음 → 전력계로 와트당 처리량 비교 예정
  • 폰은 1분 사이 13~15% 감속 → 10분 지속 측정으로 실사용 성능 확인 예정
